⚠️ 以上都是**静态验证**（镜像结构、QML 语法、配色注入）。
**上机观感尚未确认** —— 因为没有已验证的设备调试通道。

## 二、用同一套工具链**再做就能做**的

这些都是"写新的替换规则 + 跑一遍工具链"，不需要新能力。

### UI 层

| 改造 | 涉及资源 | 难度 | 备注 |
|---|---|---|---|
| 播放界面控件逐个美化 | `chunk_9` 下的播放 QML | 中 | 控件多，需逐个找替换点 |
| 文件浏览 / 库视图 | `chunk_9`、`chunk_10` | 中 | 同上 |
| 设置页每一行 | `SettingItemNormal.qml` 等 | 低 | 已经继承主题色，只需微调 |
| 状态栏 | `chunk_8` | 低 | 同上 |
| 图标替换 | `assets/images/*.png` | 中 | 注意槽位大小限制 |
| 字体替换 | 字体资源 | 中 | 需确认 Qt 能加载的格式 |
| 字符串 / 本地化文本 | 各 QML + 语言资源 | 低 | 直接替换文本 |
| 启动画面（boot logo） | **sector 0**（不是 system） | 高 | 需要动另一个 sector，风险升高 |
| 关机动画 | 资源树内 | 中 | — |

### 音效层（**与 UI 无关，另一条路**）

播放器里有独立的音效资源与参数表：

| 改造 | 说明 |
|---|---|
| EQ 曲线 | 修改预设频段增益表 |
| DSEE HX 预设 | 修改算法参数 |
| Clear Phase / VPT / DC Phase | 修改系数表 |
| 音量上限 | 修改增益表（注意听力安全与失真） |

> 这些在 `audio_candidates` 里已经定位到候选资源，但**本次未做**，
> 需要单独的逆向与听感验证。

### 主题层（性价比最高）

| 改造 | 说明 |
|---|---|
| 换主题色 | 改 `ScreenSettings.json` 里的 `bgcolor.D1/V1` —— **一个字符串替换，全局生效** |
| 换文字色 | 同文件里的 `textcolor` |
| 多套主题 | 理论上可以准备多份配置，但设备端切换机制未确认 |

## 三、**做不到** / 有硬限制的

### 架构限制

| 限制 | 原因 |
|---|---|
| ❌ **模糊效果（blur）** | 低端 Mali GPU，模糊要走 shader 或 `layer.enabled` → 每帧离屏渲染。**玻璃感只能用 alpha + 圆角 + 高光边模拟。** |
| ❌ 任意布局重排 | QML 在固定大小槽位里，**只能净减小体积**。想加内容必须先找到能腾出空间的地方。 |
| ❌ 加新解码格式 | 需要动原生解码器代码，不在 QML 层 |
| ❌ 加新协议 / 新功能 | 同上 |
| ❌ 改 UI 框架本身 | Qt 5.6 编译在二进制里 |

### 安全限制（**刻意不做的**）

| 限制 | 原因 |
|---|---|
| ❌ 改 bootloader / 内核 / TrustZone | 这些改坏了就是**硬砖**，且没有恢复路径 |
| ❌ 改 CM4 音频协处理器固件 | 同上，且可能导致音频彻底失效 |
| ❌ 刷写前不备份 | 没有恢复路径的改造 = 赌博 |
| ❌ 用来源不明的密钥 | 可能刷入被篡改的镜像 |

## 五、如果继续做，建议的顺序

1. **先刷一次当前版本**，确认菜单能弹出、玻璃效果生效、音频正常
   —— 这是所有后续工作的前提
2. 若成功，**逐个界面**加玻璃化（播放页 → 库视图 → 设置页）
3. 顺手把 `docs/05` 里列的边际优化做掉（压暗层局部化、去分隔线）
4. 音效层单独开一条线，做听感验证
5. 主题色做成可配置（甚至多套）

**不要跳步。** 每一步都要能回退。
